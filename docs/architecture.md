# Архитектура LocalVoice

## Принципы

1. **Local-first.** Распознавание выполняет CPU-версия whisper.cpp через Whisper.net. Сеть используется только для явной загрузки модели или будущего явно подключённого экспорта.
2. **Тонкий UI.** WPF + CommunityToolkit.Mvvm, ручная композиция зависимостей. WinForms используется только для `NotifyIcon`.
3. **Изоляция платформенного кода.** Win32 P/Invoke сосредоточен в `Platform/NativeMethods.cs` и сервисах.
4. **Ограниченные ресурсы.** Аудио-канал, очередь финалов, длина сессии, история и логи имеют верхние границы.
5. **Явные состояния.** `Idle → Loading → Listening → Finishing → Idle`; отдельный тест микрофона.

## Поток данных

```text
WASAPI shared mode (NAudio)
  → PCM 16 kHz / 16-bit / mono
  → bounded Channel<AudioFrame> (256)
  → energy VAD: pre-roll 300 ms, hang-over 650 ms, max utterance 12 s
  → RecognitionQueue: coalesced partials + bounded finals (16)
  → один WhisperProcessor на сессию, последовательная обработка
  → TranscriptBuffer: финальный текст важнее устаревших partial
  → UI / история / статистика / опциональная вставка
```

### Почему partial не блокирует финал

Очередь хранит максимум один partial и отдаёт приоритет финальным сегментам. Если процессор не успевает, partial отбрасывается, а финальные фразы сохраняют порядок. `TranscriptBuffer` не позволяет позднему partial перезаписать уже принятый финал.

### Завершение

При остановке микрофон закрывается, VAD отдаёт последний фрагмент, очередь закрывается для новых partial, worker дорабатывает финалы до 30 секунд. После таймаута инференс отменяется, а пользователь получает предупреждение. Аудио не сохраняется.

## Модель и память

`WhisperEngine` лениво создаёт `WhisperFactory` после проверки SHA-256. Фабрика кэшируется между сессиями; процессор создаётся на сессию и освобождается после неё. Удаление модели сначала выгружает фабрику и запрещается во время диктовки.

Используется CPU runtime order `[Cpu, CpuNoAvx]` и `UseGpu=false`. Если процессор/ВМ не поддерживает AVX/AVX2/FMA, Whisper.net выбирает поставленный NoAvx-runtime. Потоки по умолчанию — половина логических CPU, clamp 2–8; максимум в UI — 16.

## Автообновление

`UpdateService` проверяет `releases/latest` GitHub, принимает только стабильные semver-теги новее текущей, скачивает `LocalVoice-<version>-win-x64-setup.exe` и `.sha256`, проверяет размер и SHA-256. `UpdateInstallerHelper` запускает скрытый PowerShell-helper, который ждёт выхода LocalVoice, тихо запускает per-user Inno Setup и перезапускает приложение. Это избегает блокировки `LocalVoice.exe` во время замены. Автоустановка выполняется только когда контроллер диктовки, тест микрофона и менеджер моделей свободны.

## Глобальная клавиша и фокус

- `RegisterHotKey` на message-only `HwndSource`, `MOD_NOREPEAT`.
- На время сессии ставится low-level keyboard hook для `Esc` и отпускания PTT-клавиш.
- Оверлей получает `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`, показывается через `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)`.
- Цель вставки запоминается до активации LocalVoice. `SendInput` проверяет, что исходное окно всё ещё в foreground.

## Хранение

`%LOCALAPPDATA%\LocalVoice`:

```text
settings.json      настройки
history.json       ограниченная история текста
statistics.json    счётчики и последняя ошибка
models/            ggml *.bin
logs/              localvoice-YYYYMMDD.log
```

JSON пишется через временный файл + `File.Replace` с `.bak`. При повреждении основного файла используется резервный. История и статистика сериализуются через семафоры.

## Ошибки

- Нет модели → понятное сообщение и переход к менеджеру моделей.
- Микрофон отсутствует/занят/отключён → ошибка без падения, тест можно повторить.
- SHA-256 не совпал → файл не используется и удаляется.
- Очередь переполнена → совет выбрать более лёгкую модель.
- Исключения UI логируются и показываются в баннере; fatal-ошибки старта завершают приложение с сообщением.

## Расширение

Новые провайдеры экспорта реализуют `IExportProvider` и регистрируются в `ExportProviderRegistry`. Они не должны выполнять сеть в конструкторе, хранить секреты в `settings.json` или отправлять текст без прямого действия пользователя. См. [integrations.md](integrations.md).
