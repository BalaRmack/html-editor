# Проверка сборки 1.3.0

Дата: 2026-11-01. Branch: `arena/e21a0934-html-editor`.

## Windows CI

Успешный запуск: https://github.com/BalaRmack/html-editor/actions/runs/41279499571

Проверено на `windows-latest`:

- Restore/build self-contained WPF `win-x64`, .NET 8, `TreatWarningsAsErrors=true`.
- Core unit tests, включая политику окна обновления:
  - новая версия предлагается;
  - такая же/старая версия не предлагается;
  - пропуск скрывает только конкретную версию;
  - отложение истекает через 24 часа;
  - ручная проверка обходит отложение/пропуск;
  - отложение и пропуск сохраняются после перезапуска.
- App tests для `UpdateService`:
  - фоновая проверка читает только метаданные и не скачивает установщик;
  - «Скачать» загружает и проверяет установщик;
  - «Отложить» и «Пропустить» сохраняются и подавляют повторное окно;
  - установка не происходит без явной команды и ждёт свободного состояния.
- UI smoke: тёмная/светлая темы, ComboBox popup, обучение, компактный оверлей, автораскрытие по распознанному тексту, устойчивая ошибка, окно обновления с кнопками «Скачать / Отложить / Пропустить».
- Тесты живого конвейера диктовки: кадры → VAD → partial/final → остановка, медленный CPU и тишина.
- Speech smoke на реальных WAV:
  - RU: `Cpu`, текст распознан.
  - EN: `Cpu`, текст распознан.
  - RU auto language: `Cpu`, определён русский.
  - RU forced `CpuNoAvx`: текст распознан.
- Publish содержит `runtimes/noavx/win-x64` и все обязательные native DLL.
- Inno Setup per-user installer собран.
- Silent install, upgrade-in-place и uninstall smoke прошли.
- Portable ZIP и SHA-256 файлы опубликованы.

## Что не проверено автоматически

- Реальный физический микрофон, горячие клавиши, tray, no-focus overlay и SendInput на пользовательском рабочем столе.
- Полный цикл обновления с уже установленной пользовательской копии: выход → тихая установка → перезапуск → новая версия. В CI проверены политика окна, загрузка/проверка установщика, сборка, установщик поверх существующей копии и наличие updater/NoAvx в поставке.
- Поведение окна обновления поверх конкретных сторонних приложений и в полноэкранных режимах.
- Вставка именно в ZeroScript: если текст виден в LocalVoice, но не появляется в поле, используйте кнопку «Вставить» или Ctrl+V; некоторые приложения блокируют синтетический ввод.
