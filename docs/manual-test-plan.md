# Ручной план приёмки Windows

Автоматика проверяет сборку, core-логику, SHA-256 модели и headless RU/EN/auto распознавание. Следующие пункты требуют живой Windows-сессии, микрофона и пользователя.

## Установка

- [ ] Установщик запускается без запроса администратора.
- [ ] Установка идёт в `%LOCALAPPDATA%\Programs\LocalVoice`.
- [ ] Создаются ярлыки, приложение стартует после установки.
- [ ] Повторная установка обновляет файлы.
- [ ] Uninstall удаляет приложение; данные предлагаются к удалению отдельно.
- [ ] Portable-версия запускается без установленного .NET runtime.

## Трей и окно

- [ ] Левый клик по трею открывает центр управления.
- [ ] Правый клик показывает Открыть / Старт-стоп / Настройки / История / Автозапуск / Выход.
- [ ] Закрытие окна крестиком прячет в трей, процесс остаётся.
- [ ] Выход из трея завершает процесс и освобождает hotkey.
- [ ] Второй запуск активирует существующее окно.

## Горячая клавиша и оверлей

- [ ] `Ctrl+Alt+Space` работает из другого приложения.
- [ ] Оверлей появляется поверх окон и **не забирает фокус** из поля ввода.
- [ ] Повторная клавиша и `Esc` останавливают.
- [ ] PTT останавливается при отпускании.
- [ ] Переназначение сохраняется после перезапуска.
- [ ] Занятая комбинация даёт понятную ошибку и откат.
- [ ] Положение/размер/прозрачность применяются.

## Микрофон и распознавание

- [ ] Тест микрофона показывает уровень и завершается через 10 с.
- [ ] Отсутствующий/занятый/отключённый микрофон не роняет приложение.
- [ ] Русская фраза распознаётся локально.
- [ ] Английская фраза распознаётся локально.
- [ ] Auto определяет язык на типичных фразах.
- [ ] Тишина не создаёт бесконечный поток финальных фраз.
- [ ] Длинная речь ограничивается и завершается корректно.
- [ ] Отмена во время загрузки модели не оставляет микрофон включённым.

## Текст, история, модели

- [ ] Копирование кладёт текст в буфер.
- [ ] Вставка возвращает фокус в исходное поле и вставляет RU/EN.
- [ ] Автовставка выключена по умолчанию и работает только после включения.
- [ ] Вставка в приложение от администратора даёт понятную ошибку.
- [ ] История ищется, копируется, вставляется, удаляется по одной и целиком.
- [ ] Отключение истории очищает файл.
- [ ] Модель скачивается с прогрессом, отменяется, проверяется, выбирается и удаляется.
- [ ] Повреждённая модель не загружается.

## Темы, автозапуск, обновления

- [ ] Тёмная/светлая/системная темы применяются к окну и оверлею.
- [ ] Автозапуск создаёт/удаляет `HKCU\...\Run` и переживает перезапуск.
- [ ] Кнопка обновлений честно сообщает об отсутствии автообновления.
- [ ] Логи открываются и не содержат распознанный текст.

## Производительность (замерить, не обещать)

- [ ] Cold start до готового трея.
- [ ] Задержка hotkey → оверлей.
- [ ] Открытие главного окна из трея.
- [ ] Время первого partial на Small/Base.
- [ ] CPU в idle и во время диктовки.
