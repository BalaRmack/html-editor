# Приватность и данные

## Что остаётся локальным

- **Аудио:** только RAM во время диктовки/теста. На диск не пишется, в сеть не отправляется.
- **Распознавание:** локальный CPU Whisper. Облачного fallback по умолчанию нет.
- **Текст:** показывается в UI; при включённой истории сохраняется в `%LOCALAPPDATA%\LocalVoice\history.json`.
- **Настройки и статистика:** локальные JSON-файлы.
- **Логи:** события и типы ошибок без распознанного текста и аудио. Ротация по дням, удаление старше 7 дней, ограничение размера файла.

## Сеть по умолчанию

Штатные сетевые операции:

1. **Пользовательская загрузка модели** с Hugging Face. URL закреплён на ревизии, проверяются размер и SHA-256.
2. **Автообновление приложения** (с 1.2.0, включено по умолчанию, отключается в настройках). Приложение обращается к GitHub Releases, скачивает per-user установщик и `.sha256`, проверяет размер и SHA-256, затем может тихо установить обновление. Аудио, распознанный текст, история и токены не отправляются. GitHub видит обычный HTTPS-запрос версии/файла и IP-адрес.

Телеметрии и облачного распознавания нет.

## Экспорт

Удалённые провайдеры отсутствуют в базовой поставке. Будущий провайдер должен:

1. Быть явно подключён пользователем.
2. Хранить секреты в OS-protected storage, а не в `settings.json`.
3. Отправлять текст только после прямого действия **Экспорт**.
4. Иметь видимый статус подключения и кнопку отключения.
5. Не выполнять OAuth в UI-потоке.

## Буфер обмена и вставка

Копирование кладёт текст в системный буфер обмена — это действие пользователя. Автовставка по умолчанию выключена. Она использует `SendInput` в запомненное исходное окно и останавливается, если фокус изменился. Текст может остаться в буфере обмена после копирования; LocalVoice не очищает чужой буфер автоматически.

## Удаление

- История очищается в UI или отключается в настройках.
- Модели удаляются в менеджере моделей.
- При удалении установщик предлагает удалить также настройки, историю и модели; по умолчанию данные сохраняются для следующей установки.
- При тихом uninstall данные сохраняются.

## Что не гарантируется

- Другие приложения с доступом к микрофону/буферу обмена находятся вне контроля LocalVoice.
- Антивирус, DLP и политики Windows могут блокировать hooks или SendInput.
- Локальные файлы не шифруются приложением; используйте шифрование диска Windows, если это требуется вашей политикой.
