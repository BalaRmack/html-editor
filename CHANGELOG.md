# Changelog

## 1.0.0

Первый самостоятельный релиз LocalVoice вместо старого HTML-редактора.

- WPF-приложение для Windows 10/11 x64 с треем и центром управления.
- Глобальная горячая клавиша, toggle/push-to-talk, no-focus оверлей.
- Локальное распознавание Whisper.net/whisper.cpp на CPU: RU/EN/auto и другие языки.
- Менеджер моделей с закреплёнными URL, прогрессом, отменой и SHA-256.
- Тест микрофона, живой уровень, VAD, ограниченная очередь и история.
- Копирование и опциональная вставка через SendInput.
- Тёмная/светлая/системная темы, настройки оверлея, автозапуск HKCU.
- Per-user Inno Setup установщик и self-contained portable zip.
- Core-тесты и headless speech smoke RU/EN/auto в Windows CI.
- Документация по архитектуре, приватности, интеграциям и ручной приёмке.

Известные ограничения: автоматического обновления и облачных провайдеров нет;
интерактивные сценарии Windows требуют ручной проверки по `docs/manual-test-plan.md`.
