# Changelog

## 1.2.0

- Добавлено автообновление внутри приложения: проверка GitHub Releases, фоновая загрузка установщика, проверка размера и SHA-256, тихая установка и перезапуск без перехода в браузер.
- Автозагрузка и автоустановка включены по умолчанию; автоустановка ждёт, пока диктовка, тест микрофона и загрузка модели свободны. Обе опции отключаются в настройках.
- Исправлена ошибка `AVX is not supported ... noavx runtime is not available`: в поставку добавлен `Whisper.net.Runtime.NoAvx`, а движок автоматически выбирает совместимый CPU-runtime.
- В CI добавлена принудительная проверка NoAvx на реальном WAV и проверка наличия NoAvx DLL в publish/installed layout.
- Установщик дополнительно проверяется повторной тихой установкой поверх существующей копии.


## 1.1.0

- Исправлен белый текст на белом фоне в выпадающих списках: ComboBox и пункты меню теперь полностью темизируются.
- Тёмная тема стала нейтральной чёрной, без синего оттенка; добавлены контрастные popup/tooltip/checkbox.
- Оверлей уменьшен до компактной капсулы 320×64: микрофон слева, живая волна сигнала по центру, стоп справа; подробности раскрываются по клику.
- Ошибка запуска микрофона/модели больше не прячет оверлей мгновенно: причина остаётся видимой, есть повтор и переход в настройки.
- Добавлена защита от двойного срабатывания горячей клавиши.
- Добавлено встроенное обучение при первом запуске и кнопка «Обучение».
- Больше лёгких анимаций: переходы страниц, обучение, кнопки, появление оверлея; уважается системная настройка анимации.


## 1.0.0

Первый самостоятельный релиз LocalVoice вместо старого HTML-редактора.

- WPF-приложение для Windows 10/11 x64 с треем и центром управления.
- Глобальная горячая клавиша, toggle/push-to-talk, no-focus оверлей.
- Локальное распознавание Whisper.net/whisper.cpp на CPU: RU/EN/auto и другие языки.
- Менеджер моделей с закреплёнными URL, прогрессом, отменой и SHA-256.
- Тест микрофона, живой уровень, VAD, ограниченная очередь и история.
- Копирование и опциональная вставка через SendInput.
- Тёмная/светлая/системная темы, настройки оверлея, автозапуск HKCU.
- Per-user Inno Setup установщик и self-contained portable zip.
- Core-тесты и headless speech smoke RU/EN/auto в Windows CI.
- Документация по архитектуре, приватности, интеграциям и ручной приёмке.

Известные ограничения: автоматического обновления и облачных провайдеров нет;
интерактивные сценарии Windows требуют ручной проверки по `docs/manual-test-plan.md`.
